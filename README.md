# Maxima-Soma-de-Subvetor
A tarefa exige três implementações diferentes para encontrar o subvetor de soma máxima, além de uma análise de complexidade computacional.
Como compilar e executar (Ambiente Linux)

Para executar este projeto, certifique-se de ter o compilador `g++` e a ferramenta `make` instalados no seu sistema (Ubuntu, Zorin, etc.).

**Passo a passo:**

1. Abra o terminal e navegue até a pasta onde os arquivos do projeto (`ex1.cpp` e `Makefile`) estão localizados.
2. Para compilar o código, digite o seguinte comando no terminal:
   ```bash
   make
   Se a compilação for bem-sucedida, um arquivo executável chamado ex1 será gerado. Para rodá-lo, execute:
   ./ex1
